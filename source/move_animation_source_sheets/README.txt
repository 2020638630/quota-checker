Sprite sheet package for desktop pet move animations.

Files:
- walk_sheet.png        : standard walking animation, 4x2 grid
- run_sheet.png         : faster running animation, 4x2 grid
- whale_ride_sheet.png  : riding a small whale animation, 4x2 grid
- duo_run_sheet.png     : running hand-in-hand with a duplicate animation, 4x2 grid

Expected grid mapping for all sheets:
- top row    = facing left,  frame 0..3
- bottom row = facing right, frame 0..3
